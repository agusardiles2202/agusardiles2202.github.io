# Portafolio Web — Agustina Ardiles

Sitio web estático e interactivo desarrollado para presentar mis proyectos de Ingeniería en Sistemas de Información (UTN FRC), arquitectura de software y currículum actualizado.

🌐 **URL pública (GitHub Pages):** https://agusardiles2202.github.io

## Proyectos incluidos

1. **Chat Multiusuario con Memoria Inteligente:** Python, LangChain, LangGraph, Google Gemini, ChromaDB, SQLite, Pydantic y Streamlit.
2. **Aplicación de Logística e Inventario:** Python, SQLite3, Tkinter/ttk, Pytest (181 pruebas automatizadas) y Patrones de Diseño (Singleton, Factory Method, Observer, State, DAO).
3. **Plataforma de Logística en Microservicios:** Java 21, Spring Boot 3.5, Spring Cloud Gateway, Keycloak (OAuth2/JWT), PostgreSQL 17, Google Maps API y Docker Compose.
